# Kalkulačka bydlení

Jednostránková webová aplikace (čisté HTML, bez závislostí). Porovná, kolik měsíčně zbyde, když starý byt prodáte a koupíte větší, když ho pronajmete, nebo když zůstanete.

Otevřete `index.html` v prohlížeči. Tlačítko „Vymazat vše“ vynuluje pole, „Vrátit ukázku“ vrátí příklad. Čísla se ukládají jen v prohlížeči.
